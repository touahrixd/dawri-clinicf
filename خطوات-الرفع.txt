خطوات رفع لوحة العيادة على استضافة Render المجانية
====================================================

ما ستحتاجه: حساب جوجل فقط (لا بطاقة بنكية).

──────────────────────────────────────────────
الخطوة 1 — حساب GitHub (لتخزين الملفات)
──────────────────────────────────────────────
1) ادخل github.com وسجّل حسابًا جديدًا (أو استخدم حسابك).
2) اضغط + أعلى اليمين ← New repository.
3) الاسم: dawri-clinic  |  اختر Private  |  اضغط Create repository.
4) في صفحة المستودع اضغط «uploading an existing file».
5) اسحب إليها محتويات هذا المجلد كاملة:
   server.mjs + package.json + .node-version + مجلد dist
   (اسحب الملفات والمجلد معًا في عملية واحدة)
6) انتظر انتهاء الرفع ثم اضغط Commit changes.

⚠️ ملاحظة: ملف .node-version يبدأ بنقطة — إذا لم يقبل GitHub رفعه تجاهله،
سنضيف الإصدار من إعدادات Render بدلًا عنه.

──────────────────────────────────────────────
الخطوة 2 — إنشاء الاستضافة على Render
──────────────────────────────────────────────
1) ادخل render.com ← سجّل الدخول بحساب جوجل.
2) New + ← Web Service.
3) اختر «Build and deploy from a Git repository» ← Connect GitHub.
   - أول مرة سيطلب تفويض Render للوصول لحسابك — وافق.
   - حدد مستودع dawri-clinic ← Connect.
4) املأ الإعدادات:
   - Name: dawri-clinic          (سيصبح جزءًا من الرابط)
   - Language/Runtime: Node
   - Branch: main
   - Build Command: npm install
   - Start Command: node server.mjs
   - Instance Type: Free
5) إن لم يُقبل ملف .node-version: أضف Environment Variable جديدة:
   Name = NODE_VERSION   Value = 22
6) اضغط Create Web Service وانتظر 3-5 دقائق.

✅ نتيجة: رابط مثل  https://dawri-clinic.onrender.com
افتحه — ستظهر شاشة دخول العيادة (رمز الممرضة 2222).

──────────────────────────────────────────────
الخطوة 3 — بعد حصولك على الرابط (مهم!)
──────────────────────────────────────────────
أ) تسجيل الدخول بجوجل: أرسل الرابط لي أو بنفسك أضفه في:
   Google Cloud Console ← APIs & Services ← Credentials
   ← OAuth Client ← Authorized JavaScript origins:
      https://dawri-clinic.onrender.com

ب) تطبيق المرضى APK: غيّر سطر الكونفيغ إلى:
      window.DAWRI_API_BASE = 'https://dawri-clinic.onrender.com/api';
   ثم Build + cap sync وأعد تصدير APK.

──────────────────────────────────────────────
قيود النسخة المجانية (بصراحة)
──────────────────────────────────────────────
• السيرفر ينام بعد ~15 دقيقة بدون استخدام؛ أول فتحة بعده تستغرق حتى دقيقة.
• قاعدة البيانات تفرغ عند كل إعادة نشر (تعديل كود) — مناسب للتجربة.
• للاستخدام الفعلي الدائم لاحقًا: خطة مدفوعة برمز $7 شهريًا مع قرص ثابت،
  أو سيرفر VPS (Oracle Cloud مجاني دائم يتطلب بطاقة للتوثيق).
